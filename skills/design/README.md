# Design

Skills for taking a product from bland to unmistakably its own. They run in order:
`design-space` bounds what to build, `design-uplift` builds it.

| Skill | What it does |
| --- | --- |
| [`design-space`](./design-space/SKILL.md) | User-invoked (`/design-space`). A charrette that runs before any code, comp, or prototype: grounds in what exists, lands a thesis and three named anti-references, names the axes the design actually varies on, generates 4–6 mutually incompatible corners, and marks what's live, dead, and open. Output is a one-page written space. |
| [`design-uplift`](./design-uplift/SKILL.md) | The build half. Takes the space page and runs numbered exploration passes to one republished artifact — big swings, screenshot-verified renders, the small-size gauntlet for marks — reading the user's picks until the identity locks, then ships a brand toolkit and an implementation brief. |
