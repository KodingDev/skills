# Design

Skills that take a product from bland to an identity of its own. Run them in order: `design-space` bounds what to build, and `design-uplift` builds it.

| Skill | What it does |
| --- | --- |
| [`design-space`](./design-space/SKILL.md) | User-invoked (`/design-space`). A charrette that runs before any code, comp, or prototype. It grounds in what exists and sets a thesis and three named anti-references. It names the real design axes, generates 4-6 incompatible corners, and marks what is live, dead, and open. The output is a one-page written space. |
| [`design-uplift`](./design-uplift/SKILL.md) | The build half. It takes the space page and runs numbered exploration passes on one republished artifact: big swings, screenshot-verified renders, and the small-size gauntlet for marks. It reads the user's picks until the identity locks, then ships a brand toolkit and an implementation brief. |
