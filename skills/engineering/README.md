# Engineering

Skills for daily code work.

| Skill | What it does |
| --- | --- |
| [`canon`](./canon/SKILL.md) | Canon over headcanon when you study an existing system, such as a port, a library, or a bug. The system is deterministic, there is always a pointer and a source, and it was built the smart generic way. |
| [`cdk-best-practices`](./cdk-best-practices/SKILL.md) | Audits AWS CDK code against the rule catalog and produces a prioritized `file:line` report. On code written in the same session, it fixes the findings in place. |
| [`dotnet-profiling`](./dotnet-profiling/SKILL.md) | Command-line profiling and diagnostics for .NET, routed by the reader you have. `dotnet-counters`, `dotnet-trace`, `dotnet-gcdump`, and `dotnet-dump` print to stdout. Only Rider's MCP tools read dotTrace snapshots, and only Timeline snapshots. dotMemory has no agent path. |
| [`foreman`](./foreman/SKILL.md) | User-invoked (`/foreman`). Delivery orchestration for big changes: tracker tickets, one worktree branch per ticket, worker fan-out, and one human-reviewable PR per ticket per repo. Every line gets a review, and speed comes from disjoint lanes. |
| [`function-design`](./function-design/SKILL.md) | Designs and reviews functions for explicit dependencies, meaningful contracts, and one level of abstraction. Includes TypeScript and C# examples and enforcement guidance. |
| [`golden`](./golden/SKILL.md) | Builds the durable version of what is new from the start, exactly as simple as the shape of the problem. The same bar applies as a review lens. |
| [`house-style`](./house-style/SKILL.md) | Stella's review bar for every change: change shape, deep modules, control flow, names, errors, comments, STE writing, tests, and git. Includes TypeScript and React references. |
| [`lean-containers`](./lean-containers/SKILL.md) | Container image discipline for writing or reviewing Dockerfiles: slim over alpine, layer-order caching, `.dockerignore`, multi-stage builds, and digest pinning. |
| [`orchestrate`](./orchestrate/SKILL.md) | Judgment for multi-agent work: builder and critic splits, model tiers, context hygiene, and deterministic pre-extraction. |
| [`pair`](./pair/SKILL.md) | User-invoked (`/pair`). Pair-programming mode: one narrated move per turn, and the keyboard goes back to the user at each live decision. The small things are the real work. |
| [`red-team`](./red-team/SKILL.md) | User-invoked (`/red-team`). Starts an adversary subagent (fork or fresh) that argues against a point for two to four rounds. Returns a verdict: what survived, what changed, and what is still open. |
| [`rehab`](./rehab/SKILL.md) | User-invoked (`/rehab`). Rehabilitates a sloppy AI-assisted codebase. Steps: triage, fix the map that the agent reads, cut the rules file, turn prose rules into enforced checks, pay down debt behind characterization tests, and hold the line. |
