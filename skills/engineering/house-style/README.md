# house-style

The review bar that every change is written to and checked against. `SKILL.md` is the agent's copy; this file records where the ideas come from.

## Sources

- **Honest functions** is distilled from Logan Smith's [How to write the perfect function](https://youtu.be/2OMRWPOSw9s): [honesty, 11:12](https://youtu.be/2OMRWPOSw9s?t=672), [signatures, 26:00](https://youtu.be/2OMRWPOSw9s?t=1560), and [abstraction, 37:33](https://youtu.be/2OMRWPOSw9s?t=2253).
- **Deep modules** follows John Ousterhout's *A Philosophy of Software Design*.
- **Test first** follows Kent Beck's *Test-Driven Development: By Example*, with vertical slices through the public interface.
- **Writing** follows [ASD-STE100 Simplified Technical English](https://www.asd-ste100.org/).
- **Go** follows [Effective Go](https://go.dev/doc/effective_go) and [Go Code Review Comments](https://go.dev/wiki/CodeReviewComments).
