# Project Planning

Skills that turn direction into a well-formed backlog that a team can execute.

| Skill | What it does |
| --- | --- |
| [`linear-method`](./linear-method/SKILL.md) | The [Linear Method](https://linear.app/method) as working rules: initiatives and goals derived backwards, enablers vs blockers, projects of 1-3 weeks with 1-3 people, issues in place of user stories, n-week cycles that mix feature and quality work, staged design projects, and continuous launches. `direction.md` covers what to build, and `building.md` covers how to build it. |
| [`plan-project`](./plan-project/SKILL.md) | User-invoked (`/plan-project`). Takes a project from "I have ideas", with any design docs or ADRs, to a backlog that is ready for review. Steps: reconcile the intake, break the work into vertical slices, write mini-PRD tickets, sequence by dependency, assign by capacity, and shape for Jira or Linear. It reads the codebase. It writes markdown and never writes to a live tracker. |
